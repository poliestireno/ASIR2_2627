# Planificación IAW (Implantación de Aplicaciones Web)

*(Todos los desafíos se realizan en Eval. 1 y 2; la Eval. 3 corresponde a la FFE)*

## 🔵 50% RA1 + RA5
**RA1.** Prepara el entorno de desarrollo y los servidores de aplicaciones Web instalando e integrando las funcionalidades necesarias.
**RA5.** Genera documentos Web utilizando lenguajes de guiones de servidor.

🎯 **2 desafíos**

## 🟢 50% RA4 + RA6
**RA4.** Gestiona aplicaciones de ofimática Web integrando funcionalidades y asegurando el acceso a la información.
**RA6.** Genera documentos Web con acceso a bases de datos utilizando lenguajes de guiones de servidor.

🎯 **3 desafíos**

## ⚪ RA2 + RA3 + RA7
**RA2.** Implanta gestores de contenidos seleccionándolos y estableciendo la configuración de sus parámetros.
**RA3.** Administra gestores de contenidos adaptándolos a los requerimientos y garantizando la integridad de la información.
**RA7.** Realiza modificaciones en gestores de contenidos adaptando su apariencia y funcionalidades.
